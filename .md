# Poolguru Testing Automation

Python and Playwright automation testing framework for the Poolguru application.

## 1. Prerequisites

Install the following before starting:

- Python 3
- Visual Studio Code
- Git (optional, for version control)

Verify Python and pip:

```powershell
python --version
python -m pip --version
```

## 2. Create the Project Folder

Open the VS Code terminal and run:

```powershell
mkdir Poolguru-Testing
cd Poolguru-Testing
```

If the folder already exists, open it in VS Code and run commands from its root directory.

## 3. Create a Virtual Environment

```powershell
python -m venv venv
```

The virtual environment keeps this project's Python dependencies separate from other projects.

## 4. Activate the Virtual Environment

For Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

For Windows Command Prompt:

```cmd
venv\Scripts\activate.bat
```

After activation, `(venv)` should appear at the beginning of your terminal prompt.

## 5. Upgrade pip

```powershell
python -m pip install --upgrade pip
```

## 6. Install Python Packages

Install pytest and Playwright:

```powershell
python -m pip install pytest playwright
```

- **pytest:** Runs automated tests and reports pass/fail results.
- **Playwright:** Automates browser actions such as clicking, typing and navigating.

## 7. Install the Browser

```powershell
python -m playwright install chromium
```

This downloads the Chromium browser required to execute Playwright tests.

## 8. Create requirements.txt

Create a file named `requirements.txt` in the project root.

To save all packages installed in the active virtual environment, run:

```powershell
python -m pip freeze > requirements.txt
```

To install dependencies from this file later, run:

```powershell
python -m pip install -r requirements.txt
```

## 9. Verify the Installation

Check pytest:

```powershell
python -m pytest --version
```

Check Playwright:

```powershell
python -m playwright --version
```

Check installed packages:

```powershell
python -m pip list
```

## 10. Project Structure

```text
Poolguru-Testing/
├── venv/
├── tests/
│   ├── test_login.py
│   └── test_dashboard.py
├── pages/
│   └── login_page.py
├── requirements.txt
└── README.md
```

- `venv/`: Virtual environment and installed dependencies.
- `tests/`: Automated test cases.
- `pages/`: Page Object Model classes.
- `requirements.txt`: Python package dependencies.
- `README.md`: Project setup and usage instructions.

## 11. Run Automated Tests

To run all tests:

```powershell
python -m pytest -v
```

To run a specific test file:

```powershell
python -m pytest tests/test_login.py -v
```

## 12. Important Notes

- Activate the virtual environment before installing dependencies or running tests.
- Ensure the Poolguru application is running before executing tests against it.
- Do not commit the `venv/` folder to Git.
- Keep `requirements.txt` updated when project dependencies change.
- Do not store passwords, API keys or other secrets directly in test files.
